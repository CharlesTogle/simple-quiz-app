📚 How to use this app

Follow these steps to create your custom quiz:

Step 1: Prepare your material
Download or gather your study material in PDF, MD (Markdown), or PPTX format.
Step 2: Generate JSON with AI
Use AI agents like Claude or ChatGPT to convert your material into a quiz JSON file using the unified format below.
Unified question format:
[
  {
    "id": 1,
    "type": "multiple-choice",
    "question": "What is TCP?",
    "choices": { "a": "Transmission Control Protocol", "b": "Transfer Communication Protocol", "c": "Total Connection Protocol", "d": "Tactical Computing Protocol" },
    "answer": "a"
  },
  {
    "id": 2,
    "type": "abbreviation",
    "question": "HTTP",
    "answer": "HyperText Transfer Protocol"
  },
  {
    "id": 3,
    "type": "identification",
    "question": "Who invented the telephone?",
    "answer": "Alexander Graham Bell"
  }
]
Supported types:
multiple-choice — choose from a list of options
abbreviation — type the full form of an acronym
identification — type the answer to a prompt
Step 3: Load your quiz
Upload a JSON file below, or paste your JSON directly into the text area.
Troubleshooting
If you see "No questions detected":
  • Verify your JSON matches the format above exactly
  • Try re-pasting or re-uploading the file
  • Regenerate the JSON file with your AI agent
